# Hajime Japan Public Trust Library

**Purpose:** Remove the reasons a reasonable founder would hesitate to trust Hajime with a high-stakes Japan launch.

**Status:** Public-copy source library. These are not contracts or legal advice. Claims marked with a verification gate must not be published until the named evidence exists. Japanese counsel should review legally sensitive copy before launch.

**Evidence reviewed:** July 12, 2026

## Trust standard

Hajime does not ask customers to trust confidence, polish, or vague claims of expertise. Trust should come from visible boundaries, named responsibility, verifiable partner status, honest project reporting, controlled information handling, fair remediation, and a willingness to say when Hajime is not the right provider.

## Non-negotiable publication rule

Do not turn an intended control into a present-tense public claim. Before publication, each factual statement must have an owner and evidence dated within the stated review cadence. If evidence is missing, narrow the statement or leave it unpublished.
